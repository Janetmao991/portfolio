# Janet's portfolio (janetmao.com)

Static site. Pages are generated by `_src/build.py` (run `python3 _src/build.py`); never hand-edit the generated HTML.
Shared look: `assets/style.css`, with `assets/v5.css` on top (current v5 design). The build stamps `?v=<hash>` on CSS/JS links.

- Local preview: `python3 -m http.server 4321` in this folder.
- GitHub `Janetmao991/portfolio` (private) is the archive: commit and push there.
- Deploy: Janet runs `vercel --prod` herself. Not connected to auto-deploy; don't deploy for her.
